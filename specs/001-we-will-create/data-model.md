# Data Model: AI Video Generation Web Application

**Date**: September 17, 2025  
**Branch**: `001-we-will-create`  
**Phase**: 1 - Data Model Design

## Overview

This document defines the data structures for the AI video generation application. Since the application uses local storage and no authentication, all data is client-side and session-scoped.

## Core Entities

### VideoProject

Represents a complete user video project from initial prompt to final video.

```typescript
interface VideoProject {
  id: string; // UUID v4
  title: string; // AI-generated project title
  originalPrompt: string; // User's initial input
  storyboard: string; // AI-generated storyboard description
  scenes: Scene[]; // Array of 4 scene objects
  createdAt: Date; // Project creation timestamp
  updatedAt: Date; // Last modification timestamp
  status: ProjectStatus; // Current generation status
}

enum ProjectStatus {
  GENERATING = "generating", // AI generation in progress
  COMPLETED = "completed", // All scenes generated successfully
  FAILED = "failed", // Generation failed
  EDITING = "editing", // User actively editing scenes
}
```

**Validation Rules**:

- `id`: Must be valid UUID v4
- `title`: 1-100 characters, generated by AI
- `originalPrompt`: 1-1000 characters, required
- `storyboard`: 1-2000 characters, generated by AI
- `scenes`: Exactly 4 scenes required
- `createdAt`/`updatedAt`: Valid ISO 8601 dates
- `status`: Must be valid ProjectStatus enum value

**State Transitions**:

```
GENERATING → COMPLETED (successful generation)
GENERATING → FAILED (generation error)
COMPLETED → EDITING (user starts editing)
EDITING → COMPLETED (user finishes editing)
FAILED → GENERATING (user retries)
```

### Scene

Represents an individual scene within a video project (16:9 image).

```typescript
interface Scene {
  id: string; // UUID v4
  projectId: string; // Reference to parent VideoProject
  index: number; // Scene order (0-3)
  prompt: string; // AI-generated image prompt
  imageUrl: string; // Generated image URL
  imageBlob?: Blob; // Optional cached image data
  canvasPosition: Position; // Position in canvas workspace
  status: SceneStatus; // Current scene status
  generatedAt: Date; // When image was generated
  editHistory: SceneEdit[]; // History of user edits
}

enum SceneStatus {
  GENERATING = "generating", // Image being generated
  COMPLETED = "completed", // Image ready
  FAILED = "failed", // Generation failed
  EDITING = "editing", // User editing prompt
}

interface Position {
  x: number; // X coordinate in canvas
  y: number; // Y coordinate in canvas
  width: number; // Scene width in canvas
  height: number; // Scene height in canvas
}

interface SceneEdit {
  id: string; // Edit UUID
  prompt: string; // User's edit prompt
  previousImageUrl: string; // Previous image URL
  newImageUrl: string; // New image URL
  timestamp: Date; // When edit was made
}
```

**Validation Rules**:

- `id`: Must be valid UUID v4
- `projectId`: Must reference existing VideoProject
- `index`: Integer 0-3, unique within project
- `prompt`: 1-500 characters
- `imageUrl`: Valid HTTP/HTTPS URL or blob URL
- `canvasPosition`: All coordinates must be positive numbers
- `status`: Must be valid SceneStatus enum value
- `editHistory`: Maximum 10 edits per scene

**Relationships**:

- `Scene.projectId` → `VideoProject.id` (many-to-one)
- Scenes must be ordered by index within each project

### UserSession

Represents the current user's session data and preferences.

```typescript
interface UserSession {
  id: string; // Session UUID
  projects: VideoProject[]; // User's video projects
  preferences: UserPreferences; // User settings
  lastActiveAt: Date; // Last activity timestamp
}

interface UserPreferences {
  theme: "light" | "dark" | "system"; // Theme preference
  canvasZoom: number; // Default canvas zoom level
  autoSave: boolean; // Auto-save preference
  notifications: NotificationSettings; // Notification preferences
}

interface NotificationSettings {
  generationComplete: boolean; // Notify when generation completes
  errors: boolean; // Notify on errors
  tips: boolean; // Show helpful tips
}
```

**Validation Rules**:

- `id`: Must be valid UUID v4
- `projects`: Array of valid VideoProject objects
- `theme`: Must be 'light', 'dark', or 'system'
- `canvasZoom`: Number between 0.1 and 3.0
- `autoSave`: Boolean value
- `lastActiveAt`: Valid ISO 8601 date

### Storage Operations

```typescript
interface StorageManager {
  saveProject(project: VideoProject): Promise<void>;
  loadProject(id: string): Promise<VideoProject | null>;
  deleteProject(id: string): Promise<void>;
  listProjects(): Promise<VideoProject[]>;
  saveUserSession(session: UserSession): Promise<void>;
```

**Storage Limits**:

- Maximum 10 projects per user session
- Maximum 10MB total storage per domain
- Image cache: Maximum 50 images
- Auto-cleanup of projects older than 30 days

## AI Generation Pipeline

### Generation Queue

```typescript
interface GenerationRequest {
  id: string; // Request UUID
  type: GenerationType; // Type of generation
  projectId: string; // Target project
  sceneId?: string; // Target scene (for image edits)
  prompt: string; // Generation prompt
  status: GenerationStatus; // Current status
  priority: number; // Queue priority (1-10)
  createdAt: Date; // Request timestamp
  startedAt?: Date; // Generation start time
  completedAt?: Date; // Generation completion time
  error?: string; // Error message if failed
}

enum GenerationType {
  PROJECT_TITLE = "project_title",
  STORYBOARD = "storyboard",
  SCENE_PROMPTS = "scene_prompts",
  SCENE_IMAGE = "scene_image",
  SCENE_EDIT = "scene_edit",
}

enum GenerationStatus {
  QUEUED = "queued",
  IN_PROGRESS = "in_progress",
  COMPLETED = "completed",
  FAILED = "failed",
  CANCELLED = "cancelled",
}
```

## Video Composition

### Remotion Composition

```typescript
interface VideoComposition {
  id: string; // Composition UUID
  projectId: string; // Source project
  scenes: VideoScene[]; // Ordered scenes for video
  duration: number; // Total duration in seconds (8s)
  fps: number; // Frames per second (30)

interface VideoScene {
  id: string; // Scene UUID
  imageUrl: string; // Scene image URL

interface Transition {
  type: "fade" | "slide" | "zoom";
  duration: number; // Transition duration (0.5s)
}
```

## Error Handling

### Error Types

```typescript
interface AppError {
  id: string; // Error UUID
  type: ErrorType; // Error category
  message: string; // User-friendly message
  details: string; // Technical details
  timestamp: Date; // When error occurred
  context: ErrorContext; // Error context data
}

enum ErrorType {
  GENERATION_FAILED = "generation_failed",
  NETWORK_ERROR = "network_error",
  STORAGE_ERROR = "storage_error",
  VALIDATION_ERROR = "validation_error",
  AI_PROVIDER_ERROR = "ai_provider_error",
}

interface ErrorContext {
  projectId?: string; // Related project
  sceneId?: string; // Related scene
  action: string; // User action that caused error
  userAgent: string; // Browser information
}
```
